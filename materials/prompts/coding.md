# Coding prompts

## Build the Skill (run `/skill-creator` first)

```text
Create a skill for qualitative coding of ethnographic field notes
using boyd's networked publics affordances (persistence,
visibility, spreadability, searchability), plus an "other /
emergent" code.

For each excerpt: propose zero or more codes, quote the exact
evidence, give a confidence (high / medium / low) and a one-line
rationale. Never invent text that isn't in the excerpt. If nothing
fits, say so. Flag anything that looks like identifiable personal
information. Output as a table I can paste into a spreadsheet.
```

Or skip this step and use the finished `materials/skills/qual-coding/SKILL.md`.

## Open coding pass

```text
/qual-coding-networked-publics

Code the excerpts in fieldnotes.md.
```

## Axial coding and themes

```text
Looking across all the codes you proposed:

1. Which codes tend to co-occur in the same excerpt?
2. Suggest 2–3 candidate themes that connect them. For each theme,
   list the excerpt IDs that support it AND any that complicate it.
3. Do not finalise anything. Present these as options for me to
   accept, merge, rename, or reject.
```
